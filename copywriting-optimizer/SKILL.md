# 文案優化 Skill（Sugarman 12原則）

## 核心任務

依據 Sugarman 文案12原則，分析並改寫任何行銷、社群、銷售或說服性文章，使其符合心理流程、閱讀動能與轉換設計。

---

## 12 原則速覽

| # | 原則 | 核心概念 |
|---|------|----------|
| 1 | 滑梯效應 | 每句話的任務是讓讀者讀下一句 |
| 2 | 先建立前提 | 先提出讀者能接受的想法，再介紹產品 |
| 3 | 情緒先行 | 好奇→期待→擔心→希望，情緒啟動後理性才找理由 |
| 4 | 閱讀路線設計 | 標題停→開頭進→中段理由→結尾行動 |
| 5 | 清楚優先於華麗 | 像直接對話，句子簡單，無閱讀阻力 |
| 6 | 單一核心想法 | 全文只處理一個觀點，從不同角度說明 |
| 7 | 資訊缺口 | 留下未完成的問題，讓大腦保持注意力 |
| 8 | AIDA 心理流程 | 注意 → 興趣 → 渴望 → 行動 |
| 9 | Hook 三要素 | 直接開始＋資訊缺口＋句子簡短 |

## 執行流程

### Step 1：診斷原文

閱讀使用者提供的文案，逐條對照12原則，找出：
- **缺失**：哪些原則完全未使用
- **弱點**：哪些原則用了但力道不足
- **亮點**：哪些原則已經做得好

輸出格式：
```
【原文診斷】
✅ 已符合：原則 X、Y
⚠️ 待加強：原則 A（說明原因）
❌ 缺失：原則 B、C（說明影響）
```

---

### Step 2：改寫文案

依診斷結果，完整改寫文案。改寫時逐層套用原則：

#### 🎯 Hook（開頭3句）
- 第1句：製造資訊缺口或反常識陳述（原則 9）
- 第2句：擴大好奇心，埋下情緒鉤子（原則 3）
- 第3句：預告讀者繼續讀下去的好處（原則 1）

範例結構：
> 「很多人每天花30分鐘做一件事，卻從來不知道它正在傷害自己的睡眠。」
> 「不是咖啡，不是手機——而是一個你以為對身體好的習慣。」
> 「讀完這篇，你會知道要停掉哪一個，以及什麼能代替它。」

#### 📐 前提建立（原則 2）
在介紹任何產品或服務前，先建立讀者能接受的前提：
- 描述他們已有的問題或信念
- 引導讀者自己推導出「需要解決方案」
- 讓產品成為「顯而易見的答案」

#### 🧠 閱讀路線（原則 4）
確認文章結構符合四段路線：
```
標題     → 讓目標讀者停下來
開頭     → 建立情境，植入問題
中段     → 提供證據、理由、故事
結尾     → 一個清楚的行動呼籲（CTA）
```

#### 💡 單一想法貫穿（原則 6）
改寫後請確認：
- 全文能用一句話概括核心訊息
- 每個段落都是在支撐這個核心
- 刪除任何「偏題」的段落

#### ✂️ 語言清晰度（原則 5）
- 句子平均長度 ≤ 20 字（繁體中文）
- 避免行話、抽象名詞堆疊
- 每段 ≤ 4 句

---

### Step 3：標註改寫依據

改寫後，為文案每個關鍵區塊標注使用了哪條原則，方便使用者學習與二次修改。

格式：
```
[開頭]
「...」← 原則9：Hook三要素（直接開始＋缺口）
「...」← 原則3：情緒先行（好奇心植入）

[中段]
「...」← 原則2：前提建立
「...」← 原則7：資訊缺口延伸

[結尾]
「...」← 原則8：AIDA → 行動
```

每次優化輸出包含三個區塊：

```
━━━━━━━━━━━━━━━━━━━━━━━━
【1. 原文診斷】

━━━━━━━━━━━━━━━━━━━━━━━━

```

## 使用場景對應

| 場景 | 重點原則 | 特別注意 |
|------|---------|---------|
| 社群貼文（FB/IG/LinkedIn） | 1、3、7、9 | Hook前3行決定是否展開 |
| 銷售頁 / Landing Page | 2、4、8 | 前提建立要夠紮實 |
| Email 行銷 | 1、6、9 | 主旨行 = Hook第1句 |
| 診所/醫療文案 | 2、3、5 | 情緒以「希望」「擔心」為主，避免恐嚇 |
| 課程/服務介紹 | 2、4、6、8 | 先描述學員痛點，再介紹課程 |

---

## 語言與風格設定

- 預設輸出語言：**繁體中文**
- 語氣：親近、直接、有溫度（非推銷腔）
- 句子風格：短句為主，避免複合句嵌套
- 若使用者提供的是英文原文，可雙語輸出

---

## 邊界條件

- 若原文少於50字，提醒使用者提供更多上下文（目標受眾、產品/服務、期望行動）
- 若原文已有強烈原則符合，改寫保留該部分，標注「維持原版」
- 若使用者只提供主題而無原文，依主題與目標直接產出符合原則的新文案
