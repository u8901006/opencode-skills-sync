# Research to Blogger｜英文研究、全文、中文摘要與卡片網頁

把「主題＋年份＋輸出資料夾＋參考版型」轉成可追溯的研究資料包。**先核對證據，再寫摘要，最後呈現；摘要永遠不冒充全文。**

## 使用界線

- 適用：從主題開始檢索，交付單篇研究型 Blogger 頁面及本地文獻資料。
- 已有一整批 PDF、要拆成系列文章：優先 `papers-to-blog`。
- 使用者已確認版型便沿用，不重問已回答的問題。未提供圖片時不聲稱看過；先請上傳，或告知採預設版。
- 不自動發布 Blogger、部署網站、付費取文、覆寫現有研究或派遣子代理。只有使用者或適用指示授權才做。

## 輸入與檔案

先讀 [工作流程](references/workflow.md) 及 [資料契約](references/data-contract.md)。支援任意主題、年份、文獻數及卡片數；不得複製前案的 DOI、結果、18／15 計數或硬編碼文獻清單。

| 檔案 | 用途 |
|---|---|
| `project.json` | 題名、日期範圍、實際截止日、分類與檢索限制 |
| `papers.json` | 已核實書目、中文摘要、讀取層級、全文相對路徑與授權 |
| `cards.json` | 每張卡片的短文、分類與來源 ID |
| `article.html` | 綜合文章；引用 `#at-ref-R01` 形式 |
| `search/`、`fulltext/` | 原始檢索、取得紀錄及合法英文全文 |

## 執行流程

1. **界定問題。** 區分直接對象、一般族群、理論個案與治療研究；以首次正式出版日篩選，保留不同的卷期年。當年度只到實際日期。
2. **檢索並留證。** 學術資料庫優先；搜尋工具失效可用 Europe PMC API。分年／分頁直到取完，保存查詢、hitCount、游標與原始結果。以 DOI 去重，核對作者、真正期刊名、語言、撤稿與日期。不把單資料庫選文自稱系統性回顧。
3. **取得全文。** 優先合法 OA PDF、JATS XML 或公開作者手稿。檢查檔案內容，不只 HTTP 200／副檔名。登入頁、摘要頁、403 和 OA 但下載失敗都不是已取得全文；記錄來源及缺口，不繞過限制。
4. **逐篇解讀。** 寫方法、對象、發現、限制及意義，明示依全文或僅摘要。讀結果與方法，不只摘要；保留反方向、未顯著結果、樣本重疊及異質性。前後測不等於對照效果，效應量不等於康復率，統計中介不等於因果。
5. **製作頁面。** 預設深藍標頭、四種分類、白底圓角編號卡片；桌面三欄、手機單欄，先快覽再長文、FAQ、方法與引用。卡片數不是研究篇數；不湊數編造證據。按契約準備四份輸入後執行下列指令。
6. **驗證與交付。** 執行資料／內容檢查及實際瀏覽器測試，讀桌面與手機截圖。只宣稱實際完成的檢查。交付預覽、貼上版、摘要、全文、CSV、BibTeX、檢索紀錄與 README；報告取得篇數及未取得原因。未測 Blogger 真實主題就明說。

## 指令

`<skill-dir>` 是此 skill 的絕對目錄；所有路徑加引號。

```powershell
python "<skill-dir>/scripts/publish.py" --project "<研究資料夾>"
python "<skill-dir>/scripts/publish.py" --project "<研究資料夾>" --check
python "<skill-dir>/scripts/browser_check.py" --project "<研究資料夾>"
```

產物已存在時預設拒絕；只有確認是本次生成檔且有必要重建，才使用 `--overwrite-generated`。這不授權刪除來源或其他使用者檔案。工具不會檢索或自動撰寫研究；不可用空白／假資料換取綠燈。瀏覽器工具缺依賴時改用可用瀏覽器實測，或明記未驗證，不自行安裝軟體。

## 常見錯誤／停止訊號

| 誘因 | 必須採取的處理 |
|---|---|
| 「舊案已測過，直接交付」 | 新主題計數、引用、內容及版面重新驗證 |
| 「OA／200 所以有全文」 | 檢查正文、DOI、格式及授權；失敗明記 |
| 「12 卡應有 12 篇」 | 卡片與文獻分開；可整理限制，不編造來源 |
| 「先求好讀，省略負向結果」 | 保留反例、零結果與重要限制 |
| 「測試全過所以已發布」 | 區分資料檢查、本地視覺測試及真實 Blogger 發布 |

**完成的核心：可追溯、可閱讀、不過度推論；不是用漂亮版型掩蓋證據缺口。**
