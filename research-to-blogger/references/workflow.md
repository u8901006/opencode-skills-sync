# 執行細節與研究品質閘門

## 1. 啟動

將使用者輸入整理為主題、起訖年、語言、儲存資料夾、讀者與版型。缺少的次要參數採合理預設並說明；已確認的設計不用再次確認。新主題不要複製前案文獻。資料夾已存在時先盤點，不覆蓋來源。

預設繁體中文、一般讀者、敘述性研究整理；沒有證據不保證固定研究篇數。可有 9–12 張快覽卡，卡數依內容調整；使用者指定數量就用重點卡與限制卡，不用假文獻湊數。

## 2. 搜尋與核對

建立概念組而不只搜長句，例如：

1. 直接族群 AND 主題／暴露。
2. 機制或結果 AND 暴露。
3. 介入 AND 結果 AND（review OR randomized）。

依題目採對應資料庫。醫療／心理可用 PubMed、Europe PMC；人文與藝術的涵蓋不足應補相關期刊或學術索引，不能只用 Europe PMC 就聲稱全面。如果無法使用其他來源，清楚說明涵蓋限制。

Europe PMC 可用：

```text
https://www.ebi.ac.uk/europepmc/webservices/rest/search
  ?query=(TITLE_ABS:keyword AND TITLE_ABS:outcome)
     AND FIRST_PDATE:[YYYY-01-01 TO YYYY-MM-DD]
  &format=json&resultType=core&pageSize=100&cursorMark=*
```

實際發送前 URL encode。每頁保存完整 JSON、查詢、讀取時間與 cursorMark；若 hitCount 超過當頁回傳筆數，用 nextCursorMark 繼續，不假裝只取第一頁已搜完。分年可減少單次結果，但也要檢查各年是否完整。

`https://api.crossref.org/works/<DOI>` 用於作者、題名、真正期刊名、卷期、頁碼及授權核對，不把 Crossref 書目查詢冒充完整主題搜尋。遭 429 時降低請求量，先依原文核對並記錄，勿密集重試。

年份以首次正式出版日為預設。線上先行早於範圍、卷期落在範圍者不得悄悄納入；可列背景並說明。只有月份時保留原精度，不捏造 1 日為確切日。預印本及正式版不重複計數。檢查 retract／withdraw／correction；撤稿不作主要證據。保存排除原因，未讀完的候選標「未完整評讀」，不要冒稱通過雙人篩選。

範圍外背景另放 `background/`，不要放 `papers.json`（此表只放範圍內的選定研究）。背景若需網頁提及，用一般 HTTPS 來源連結並明標範圍外，不沿用主要文獻計數。

## 3. 合法全文

- Europe PMC JATS：`https://www.ebi.ac.uk/europepmc/webservices/rest/<PMCID>/fullTextXML`。
- PMC：`https://pmc.ncbi.nlm.nih.gov/articles/<PMCID>/`，注意公開作者手稿與出版版不同。
- 出版者／機構典藏／作者公開版本：尊重原授權，不繞過付費或反自動化。
- 不要求 PDF 才算全文，但必須標 XML、HTML、TXT 或作者手稿；不要改副檔名冒充 PDF。
- XML 需有 article body；PDF 需 `%PDF-` 且人工或工具確認正文；HTML 要有完整正文，不是 abstract、登入或挑戰頁。
- 保存來源 URL、取得日期、版本、授權、檔案大小與 SHA-256。只取得摘要也要保存來源，不造 `fulltext.pdf`。
- 轉換文字閱讀版不得假裝與出版排版等同；圖版、公式和表格未保存須揭露。原始 XML／PDF 為本地權威副本。
- 個人研究保存不等於可整包公開散布。ND／NC、第三方圖版、作者手稿等限制分開記錄。Blogger 只放自己的中文綜合解讀與來源連結，不內嵌原全文或英文摘要。

## 4. 解讀順序

每篇先記「已讀全文／僅摘要／公開手稿」。若取得全文但未讀，先讀，不能把 read_level 填成 fulltext 只為計數。沒有全文就避免補造方法細節。

方法 → 對象與測量 → 結果含非顯著值 → 討論與限制 → 原始摘要。對每個文章主張核對：

- 對象真的是目標族群嗎？學生不等於藝術家／照顧者。
- 測量是自陳興趣、行為任務還是作品品質？不可互換。
- 是理論閱讀、個案、質性、相關、追蹤、RCT 或統合分析？
- 數值是前後測、組間差、相關、OR、p 值還是比例？不要混用。
- I² 高、信賴區間寬、結果不一致、樣本重疊與多重比較有無影響推論？
- 不能由分組顯著／不顯著就推定組間效果差；不能跨不同回顧的效應量直接排療效高低。
- 模型的中介與調節不是因果；周邊生物標記不是直接腦內測量。

中文摘要欄位見契約。重要疑點留在摘要與綜合文章，不只藏在機器資料裡。

## 5. 寫作與視覺

預設結構：結論 → 名詞區分 → 直接研究 → 間接／相反證據 → 實務意義 → 安全提醒 → FAQ → 檢索方法／缺口 → 引用。

卡片：編號、短標題、文字分類、研究設計／人數、重點一句、限制一句、來源 ID。分類依證據直接性或題目設計，不預設綠色就是「療效確定」。不要用大字把小樣本相關研究寫成定論。

預設視覺保留深藍大標頭、青綠／紫／藍灰／莓紅分類、白底圓角、淺底色。桌面三欄、手機一欄；不抄原參考圖的醫療內容、logo、吉祥物或人物。引用與分類有文字，不能只靠顏色區分。

Blogger 片段只有局部 `<style>` 和文章，不含文檔外殼、全域選擇器、外部框架或 JavaScript。來源 DOI 為公開 HTTPS，不帶本機磁碟路徑。額外生成獨立 preview 與本地 archive index。

## 6. 驗證與交付

生成工具驗證的是資料契約、檔案基本內容及引用結構，**不是文獻真實性或療效品質的自動保證**。仍需人工核對研究與來源。

生成時保存四份輸入的雜湊，`--check` 能指出輸入變更後未重建的情形；不取代逐段核對生成物。XML 允許命名空間，正文長度門檻只擋明顯空檔，不能單憑長度認定完整。PDF 簽名檢查更不是全文完整性檢查。瀏覽器截圖只涵蓋首個視窗，須另外向下捲動檢查長文與引用，或用可用工具補完整頁面截圖。

1. 篇數依資料動態計算，全文以文章計數而非檔案計數。
2. 引用皆能對應；沒有沿用前案 DOI、卡片數或虛構結果。
3. 本地全文打開不是登入頁；書目與原文一致，保留授權。
4. 瀏覽器測至少 1120、768、390、360px；檢查欄位、溢出、跳轉、錯誤並閱讀截圖。Blogger 窄文章欄仍可能需主題內測試。
5. README 教使用者用文字編輯器複製原始碼，貼進 Blogger HTML 檢視；若主題移除 `<style>`，將 `templates/styles.css` 放主題自訂 CSS。
6. 報告已保存全文與摘要數、缺漏及版面驗證範圍，不說已發布。明確寫出單資料庫、未雙人評讀、非系統性回顧等限制。

不得直接把此 skill 的 `example/` 示範資料當成真實研究交付。首次應用與每次新主題都重新驗證。
